# My-first-game
Star Catcher

This is a small game i made using html css and js. you move the green box around and try to get the yellow stars where the  red boxes move around so dont touch them.

how to run:
just open index.html in your browser. no need to install anything.

how to play:
You are required to get stars to get points.And every 10 points you go up a level and it gets a bit faster. In the game you have 3 lives and 60 seconds. if you survive you win.

controls:
arrow keys or WASD to move
P for pause
M for sound on/off
R to restart
there are also buttons on the screen for mobile

files:
index.html for the layout
style.css for the look
script.js for the game stuff

thats it. have fun.
